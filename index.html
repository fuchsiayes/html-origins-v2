The Invention Of HTML - And How It Changed typography

History

Tim Berners Lee originally created HTML to help view and format important documents in

his physics work in 1989.

The WWC allowed the use of it on the web in 1993, and allowed the web to be open source.

After releasing it, many sites like Mosaic in 1993 would add more into the code for their

site.

Typography

Uses typographic instruction to make the website.

formatting commands were derived from the commands used by typesetters to manually format

documents.

Design

Created a way for anyone to make a webpage

Created a new medium of design
